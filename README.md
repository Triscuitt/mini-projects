# 🚀 Mini-Projects Collection

A curated collection of small, focused programming projects built for **learning**, **experimentation**, and **fun**. Each project is self-contained and demonstrates different web development concepts, algorithms, and creative coding ideas.

## 📁 Projects

### 🎓 **JavaScript Fundamentals**
- **JS-Beginner** — Master the basics of JavaScript
  - Variables, operators, and core concepts
  - Interactive examples and exercises
  
- **JS-algorithm** — Algorithm practice and problem-solving
  - Classic algorithm implementations
  - Building computational thinking skills

### 💻 **Web Development Projects**
- **Product-card** — Modern product card UI component
  - HTML/CSS responsive design
  - Perfect for e-commerce interfaces

- **Love-letter** — Interactive love letter experience
  - Photo carousel with styling
  - Romantic interactive web project
  - Beautiful CSS animations and effects

- **chibi** — Creative web experimentation
  - JavaScript interactivity
  - Unique styling and animations

- **message-looper** — Message display and looping system
  - Dynamic message handling
  - Interactive web interface

### 📚 **Academic Work**
- **BSCS2A_Bendoy_Lab2** — Computer Science lab assignments
  - 5 problem sets covering programming concepts
  - Solutions and implementations

## 🎯 Purpose

This repository serves as a learning portfolio showcasing:
- Web development fundamentals (HTML, CSS, JavaScript)
- Algorithm and problem-solving skills
- Progressive learning from basics to more complex projects
- Creative coding and experimentation

## 🛠️ Tech Stack

- **Languages**: JavaScript, HTML, CSS
- **Concepts**: DOM manipulation, algorithms, responsive design, animations

## 📖 How to Use

Each project folder contains all necessary files. Simply open the `index.html` files in your browser or review the JavaScript files for code walkthroughs.
